# Off Sight

Off Sight is a Unity prototype about exploring a server room, viewing a server's camera displays, and connecting RJ network cables.

## Open and play

Open this folder in Unity Editor **6000.3.20f1**. The main scene is `Assets/Scenes/SampleScene.unity`.

- Move with **WASD** or the **arrow keys**.
- Press **E** near the server to interact; press **E** again to leave.
- Hold the **left mouse button** and drag an RJ connector to a server port, then release to connect it.
